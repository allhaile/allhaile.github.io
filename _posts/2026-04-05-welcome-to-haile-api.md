It's been a while since I've updated this site, and a lot has changed.

I decided to rebuild my portfolio from scratch with a concept I've been sitting on for a minute: **Haile API** — treating my personal site like a developer interface. Endpoints instead of nav links. JSON responses instead of stat cards. Because at the end of the day, everything I do is about building interfaces — so why not make the portfolio itself one?

## What's new

- **Fresh design** — Dark mode, monospace vibes, clean layout. No more Bootstrap templates.
- **Blog** — You're reading it. I want a place to write about what I'm learning, building, and thinking about.
- **RSS feed** — Old school, but it works. Subscribe at [`/feed.xml`](/feed.xml) if that's your thing.

## What's next

I've got a few posts in the pipeline about frontend patterns I've been exploring, some thoughts on the state of web development, and maybe a deep dive into a side project or two.

If you want to follow along, grab the RSS feed or just check back here. More soon.
